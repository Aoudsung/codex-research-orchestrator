# Codex 接入

第一次使用本技能或切换客户端时读取。这里将研究职责映射到 Codex 能力，不要求安装额外的代理框架。

## 入口与项目

通过 `$codex-research-orchestrator` 或技能选择器进入。遵守当前 `AGENTS.md`、工具说明和实际权限；本技能不能扩大它们。复用工作区和既有研究入口，研究状态写在项目目录，安装的 skill 目录只保存通用规则。

优先发现现有工具和项目配置，只读足以确定下一步的资料。用文件搜索定位原文，大日志先过滤再读取。读写、联网和执行是否可用，以当前 Codex 会话实际暴露的能力为准。

## 能力映射

| 科研需要 | Codex 中的做法 | 能力缺失时 |
|---|---|---|
| 主研究与编排 | 当前对话承担目标、语义、调度和验收 | 保留单代理工作方式 |
| 并行调查与独立推理 | 使用现有子代理工具；独立工作选择不继承评价的上下文，并限定资料 | 自己完成必要分析，标为自查；独立审阅要求仍未满足 |
| 常驻合作方 | 在用户已授权时使用会话读取、消息和等待工具，复用项目绑定 | 产出可转交的完整材料，不假称已发送 |
| 代码修改与验证 | 使用工作区文件工具、终端、适用测试和实际获准环境 | 交付方案或代码，明确尚未执行的验证 |
| 长实验 | 保留作业或终端会话标识，使用完成通知或等待接口，读取关键输出 | 保存接回步骤，不重复启动 |
| 外部研究合作 | 优先连接器或 MCP；确有需要且可用时使用浏览器 | 继续本地独立工作，说明缺少外部意见 |
| 跨时段续接 | 用户要求时使用 Codex 当前提供的自动化功能 | 留下检查点，不承诺后台推进 |

工具名称会随客户端变化。发现当前工具后按其说明调用，不凭此文档猜接口，也不通过私有数据库或读取凭据绕过缺失能力。

## 子代理

优先使用当前环境已有角色和实际模型配置。常见的调查、执行、审阅职责可分别映射到只读探索者、写入执行者和独立审阅者；名称不固定。不得自动覆写用户的 `.codex` 配置、安装模型服务或授予更多权限。

一次委派给出必要上下文和明确边界。独立审阅应避免继承父对话的评价；若当前工具支持关闭历史继承，使用该能力。仅限制提示词不足以保证上下文隔离时，说明实际独立性。子代理回执统一交主研究者汇总，避免多个代理同时修改总状态。

用户已有常驻会话绑定时，临时子代理只负责其获准的独立子任务。创建用户可见的新会话、给其他会话发消息和使用外部服务，分别遵守对应工具的授权要求。

## 自动化边界

当前轮次内自动推进与跨时段调度分别处理。前者由 Codex 在任务范围内继续行动；后者需要用户请求和宿主调度。暂停、预算和外发限制写入可续接记录，不能靠上下文中的模糊承诺维持。

本技能中的控制是代理工作规则和可检查记录，不是操作系统沙箱，也不是强制的预算计费服务。实际权限由 Codex 和执行环境控制。
