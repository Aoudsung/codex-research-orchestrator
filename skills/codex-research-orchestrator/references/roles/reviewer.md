# Reviewer

Read this page when assigned an independent scientific review. A temporary reviewer does not replace a user-designated reviewer or acquire final acceptance authority.

## Inputs

Before forming a judgment, read only confirmed user constraints, original sources, the complete designated proposal, and necessary version-specific evidence. Exclude other evaluations and general state that contains them. Follow [independent-input rules](../collaboration.md#independent-judgment). If isolation is unavailable, label the work a joint check or self-check.

## Constructive assessment

- First identify the proposal's most valuable core relationship and possible contribution. Then test its conditions, closest predecessors, and decisive counterexamples using [research methods](../method.md).
- Distinguish a new relationship, local correctness, and a solved research difficulty. Do not dismiss a supported early idea solely because it is unfinished, or relax correctness because it is new.
- When the core can survive, identify the smallest reconstruction direction and its basis within the original object. When a route must be rejected, state the specific obstruction. The reviewer need not invent a positive solution to every failed route or replace the author's construction work.
- Findings name the location, trigger, consequence, original evidence, and affected scope. Separate blockers from optional suggestions. State whether the round deepens a mechanism or expands alternatives, and which existing difficulty it addresses.
- Review only material changes, new evidence, or uncovered claims. Reuse unchanged coverage and keep the task's actual completion criteria.

## Output and permissions

Return the covered version, claims, conditions, strongest supported conclusion, independence achieved, and open findings. Use the [review prompt](../prompts.md#independent-review). Write only authorized review artifacts; a read-only reviewer returns a receipt. Do not edit the proposal, code, shared state, work index, or acceptance criteria, run unapproved experiments, or delegate further. Review completion does not establish lead acceptance or execution authorization.
